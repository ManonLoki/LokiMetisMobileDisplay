## 主要链路

**Android 实时连接**：DisplayApplication 持有唯一 AndroidLanEngine；Selector owner 管理发现、TCP、分帧和计时，通过 JNI 调用编入 App 的 Rust 桥。Compose 页面和悬浮窗订阅同一展示投影。

**Android 后台与存储**：前台服务只延长同一引擎的后台连接资格，不创建第二个引擎。实时主面板只在内存；配对秘密由 Keystore 保护，图片与 Widget 摘要单独落盘。JobScheduler 可独立读取只读 HTTP 摘要。

**Apple 主应用**：SwiftUI 多窗口共用 LanLinkModel 与串行 LanLinkEngine。Network.framework 负责发现和 socket，C ABI 调用 Rust 协议；Keychain 保存配对，私有缓存保存图片，App Group 共享主应用缓存及组件摘要。

**iOS Widget**：Widget 扩展通过 Timeline 读取 App Group，可使用独立只读权限向电脑请求加密摘要并条件写入共享缓存。摘要不包含正文和图片。

**Apple Watch**：Watch 是独立应用，拥有自己的缓存和 Keychain。配对及完整图文经 iPhone 的 WatchConnectivity；手机不可达时可独立请求电脑摘要，不直接读取 iPhone App Group。

**共享代码与后台**：Rust 配对、认证与加密规则来自桌面源码，分别编入 Android 和 iPhone，不拥有平台网络或存储。Watch / Widget 的 HTTP 使用原生客户端。Apple 普通后台关闭长连接，系统可以调度短时刷新。
