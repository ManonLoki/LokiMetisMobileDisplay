# 09 v1.0.6 发布与 UI 验证

日期：2026-10-22。回到 [项目说明](../README.md) ｜ [文档索引](README.md)。

## 本次变化

- Android 原 `sharedUI` 合入 `androidApp`，应用入口与 Compose 界面归同一模块。
- Android、iPhone / iPad、Widget 和 Watch 实际复用 SharedLogic 中的展示、连接时限、图片缓存、只读 HTTP 与 Watch 传输规则；系统网络、存储、图片解码和原生界面保留在各平台。
- 清理重复实现，保留既有数据格式、配对加密协议和平台生命周期。共享规则的范围与历次验证见 [KMP 分层与优化路线](08-KMP分层与优化路线.md)。
- 修复 iPad 从“自定义面板”点击侧栏“展示台”后仍停留在设置子页的问题。切换主入口时重置导航容器，保留连接模型和本机偏好。
- 修复 Watch Hooks 上下翻页后卡片错位、标题被裁，以及冷启动恢复 Hooks 时首卡不能翻动的问题。改为按活动卡逐张吸附，初始位置由滚动容器报告，保留当前可见卡片的动图播放门禁。
- README 按“主要 UI 展示 + 详细使用说明”组织，使用隔离演示数据展示图文面板，并补充配对、布局、Hooks 详情、后台同步、悬浮窗、小组件和 Watch 的操作步骤。
