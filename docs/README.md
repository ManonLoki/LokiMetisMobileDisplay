# LokiMetrisDisplay 项目文档

LokiMetrisDisplay（中文名“诡秘神谕”）是桌面端 LokiMetris 的**移动端显示终端**：桌面负责统计各 AI 编程工具（Codex、Claude Code、Cursor、Grok、WorkBuddy 等）的 Token 用量、账户剩余额度和 Agent 实时活动（Hooks），手机、平板、手表和小组件负责“在桌面之外随时看一眼”。

## 一句话看懂整体

```
桌面 LokiMetris ──(局域网加密 TCP，配对后认证)──▶ iPhone App ──(WatchConnectivity 分块)──▶ Apple Watch
       │                                              │
       └──(局域网加密 HTTP，只读摘要)──▶ 小组件 / Watch 后备      └──(App Group 共享缓存)──▶ 小组件
```

- **在 Apple 这一侧，iPhone／iPad 主 App** 持有桌面配对秘密，负责认证、接收完整快照与图片，再分发给 Watch 和小组件。
- **Apple Watch** 不直接连桌面的主通道：优先从 iPhone 取数据；iPhone 不可达时，用 iPhone 授予的**只读 HTTP 配置**自己向桌面拉摘要。
- **iOS 小组件** 读取 App Group 里的最近一次摘要；被系统唤醒时也可用只读 HTTP 自行刷新。
- **Android** 端功能对等（含桌面小组件与悬浮窗），共享同一套 Rust 配对／加密核心和 Kotlin 协议逻辑。

## 术语表

| 术语 | 含义 |
| --- | --- |
| 快照（snapshot） | 桌面一次推送的完整展示数据：Token 用量、额度、Hooks 插槽及其图片清单 |
| Hook／插槽 | 某个 Agent 当前的活动状态（运行、询问、出错、空闲），可附正文和一张图片（支持动图） |
| 摘要（summary） | 去掉正文和图片后的精简快照，供小组件和 HTTP 使用 |
| owner | 独占某类可变状态的对象，所有读写只在它自己的串行队列上进行（例如 `LanLinkEngine`） |
| 代次（generation） | 每次重连、切换来源都会递增的整数，用来丢弃旧连接迟到的回调 |
| 租约（lease） | “最近 45 秒内真的通信过”的证明，过期即视为不可达，不靠系统状态推断在线 |
| 只读 HTTP 配置 | 桌面在认证快照里授予的独立密钥和端口，只能读取摘要，拿不到配对秘密 |
